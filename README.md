# Personal Developer Portfolio

A responsive personal portfolio website built to showcase my background, skills, projects, and interests in software and web development.

🌐 **Live Website:** [my-portfolio-mshamsan-dev.vercel.app](https://my-portfolio-mshamsan-dev.vercel.app)

## About the Project

This project is my personal developer portfolio and one of my first practical web development projects.

I built it to apply and strengthen my knowledge of:

* HTML
* CSS
* JavaScript
* Responsive Web Design
* Basic DOM manipulation
* Git and GitHub
* Web deployment with Vercel

The project is intentionally built with standard web technologies without a frontend framework, allowing me to strengthen my understanding of the fundamentals before moving to more advanced tools and frameworks.

## Features

* Responsive design for desktop and mobile devices
* Navigation between portfolio sections
* Hero section
* About section
* Skills section
* Projects section
* Contact section
* Smooth scrolling navigation
* Dark Mode / Light Mode
* Simple CSS animations
* Responsive layout

## Technologies Used

* **HTML5** — Page structure and semantic content
* **CSS3** — Styling, responsive design, animations, and dark mode
* **JavaScript** — DOM manipulation, smooth scrolling, and theme switching
* **Git** — Version control
* **GitHub** — Source code management
* **Vercel** — Website deployment
